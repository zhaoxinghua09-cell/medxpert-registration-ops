A medical-device registration operations team: a registration navigator leads the effort, coordinating AI device compliance, ISO 13485 quality systems, international market access, and registration strategy to deliver complete registration roadmaps. Covers NMPA / FDA / CE / Japan PMDA / ASEAN·LATAM·Middle East pathways, plus AI compliance topics such as SaMD, EU AI Act, PCCP, and ISO/IEC 42001.

## Type

Team type (multi-role collaboration): Registration Navigator (lead) + Compliance Officer + Documentation Controller + Market Access Officer.

## Capabilities

- Four parallel SOP lines: AI compliance scouting → international market-access scouting → primary path ruling → system/document gap analysis → roadmap compilation
- Outputs: registration roadmap, primary-path ruling memo, compliance gap report, country-by-country market-access roadmap (7-column format), CE technical documentation & GSPR matrix, ISO 13485 4-tier document system, CAPA closure, audit question bank
- Knowledge base: pairs with the separately installed MedXpert medical-device registration knowledge base v0.7 (L0–L4, including decision engine and regulatory timeline)

## Usage Examples

- "We have an imaging software with AI-assisted diagnosis, want to enter the EU first then SE Asia, and only have an old quality manual — help me produce a registration roadmap"
- "Should this AI device go 510(k) or De Novo?"
- "Produce a Saudi SFDA registration market-access roadmap"
- "Build an ISO 13485 4-tier document system from scratch"
- "Our MDR notified body audits next month — help me build an audit question bank"

## Install

Place the expert package directory under your expert directory:

```
C:\Users\<username>\.workbuddy\plugins\marketplaces\my-experts\plugins\medxpert-registration-ops\
```

After installation, WorkBuddy's open platform auto-registers and makes it visible; for local manual import, place the directory under the expert plugin directory — no extra script needed.

## Knowledge Base Companion (optional but recommended)

This team is a methodology layer; facts follow the MedXpert medical-device registration knowledge base v0.7. To cite specific regulation texts, country pathways, and the decision engine, install that knowledge base companion package separately.
